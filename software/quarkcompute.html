About QuarkCompute

QuarkCompute is a high performance computing system capable of billions of parallel calculations in seconds. This is done by utilizing Intel® Hyper-Threading and Clustering to run fragments of a large iterable calculation in parallel.

Features

QuarkCompute leverages advanced parallel processing techniques to maximize computational efficiency. With all that performance QuarkCompute also comes with a built in profiler to see exactly what compute core has slowed down the compute.

  • Secure SSH based communication
  • MultiSite WAN support
  • Built-in performance profiler
  • Multi-Language support
