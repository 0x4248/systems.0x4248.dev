About ZLinux

ZLinux is a Linux® distribution built for Z System. It is based on Debian and includes all the necessary packages and configurations to run on Z System.

ZLinux Enterprise

Full ZLinux installation with all the necessary packages and configurations.

ZLinux Core

Recuded size, still includes core networking utilities, COBOL, C, and Fortran support. Ideal for small LXC / Docker® containers.

ZLinux Lite

Minimal installation, only includes ZLinux software, no additional packages.

All your favorite sysadmin tools and core components included

ZLinux comes pre-installed with a comprehensive set of sysadmin tools and core components, making it ready for deployment on Z System.


  • Remotely manage your server using Cockpit, Webmin, or SSH.
  • Control a ZLinux cluster from the ZMP (Z Management Platform) COMMING SOON
  • Use MVS TK5 for Mainframe emulation and development.
  • Use ZLinux Auditor to monitor changes and compliance scripts
  • Includes core development tools for COBOL, C, and Fortran.
