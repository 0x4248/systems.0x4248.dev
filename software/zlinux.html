ZLinux

A Linux® Operating System, built on top of Debian with all the features for Z System. One file deployment script on a Debian-based system and its ready to go.

About ZLinux

ZLinux is a Linux® distribution built for Z System. It is based on Debian and includes all the necessary packages and configurations to run on Z System.

ZLinux Enterprise

Full ZLinux installation with all the necessary packages and configurations.

ZLinux Core

Recuded size, still includes core networking utilities, COBOL, C, and Fortran support. Ideal for small LXC / Docker® containers.

ZLinux Lite

Minimal installation, only includes ZLinux software, no additional packages.
