About Quark

Quark is a lineup of high-performance machines designed for maximum computational power and flexibility. Each unit is built to push the limits of modern hardware, providing unparalleled performance for demanding workloads.

Z Quark Lineup

Z Quark GX

The Z Quark GX is the high-end model, offering maximum computational power for the most demanding workloads.

Z Quark S

The Z Quark S is a storage server designed for high-capacity data storage and efficient data management. Z Quark S complements the high-performance Z Quark GX whilst keeping fast writes using direct attached copper to reduce latency
